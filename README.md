# LandCover.ai semantic segmentation

Отдельный исследовательский проект для курсовой работы по теме
«Исследование влияния различных архитектур нейронных сетей на эффективность
решения задачи компьютерного зрения».

## Вопрос исследования

Как decoder-архитектура влияет на качество сегментации дорог, зданий, леса и
воды на аэрофотоснимках при одинаковом encoder-е, обучении с нуля и строгом
разделении исходных сцен между train, validation и test?

## Статус

Этап аудита данных завершён в Kaggle:

- LandCover.ai: 41 исходная RGB-сцена и 41 ручная пиксельная маска;
- классы: фон, здания, лес, вода, дороги;
- создан scene-level split: 29 / 6 / 6 сцен;
- seed split: `20261004`;
- официальный tile-level split набора не используется для основной оценки,
  поскольку тайлы одной сцены попадают в разные части.

## Структура

- `notebooks/` — экспортированные Kaggle-ноутбуки;
- `src/` — код данных, моделей, обучения, оценки и визуализации;
- `configs/` — неизменяемые конфигурации экспериментов и split;
- `docs/` — протокол исследования и журнал решений;
- `artifacts/` — CSV, графики и примеры inference; не хранит датасет.

## Воспроизводимость

Основной эксперимент запускается в Kaggle. Каждая серия сохраняет в
`artifacts/runs/<run_id>/` неизменяемую конфигурацию, историю обучения,
метрики, метрики по сценам и визуальные примеры. Весовые файлы не попадают в
Git; итоговые CSV и изображения, используемые в отчёте, могут храниться в
репозитории.

Перед основным запуском папка `src/` добавляется в Kaggle как небольшой
dataset с кодом или загружается вместе с ноутбуком. Сырые GeoTIFF-файлы
LandCover.ai остаются Kaggle Input.

Датасет не копируется в репозиторий: в Kaggle он подключается как Input.
