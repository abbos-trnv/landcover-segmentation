# Журнал выполнения

## 2026-10-04 — техническая валидация pipeline

1. Проведён аудит LandCover.ai и зафиксирован scene-level split 29/6/6.
2. Построен индекс 12 006 тайлов 512x512 px: train=8 677, val=1 781,
   test=1 548. Крайние тайлы дополняются нулями в изображении и кодом 255
   в маске; код 255 исключается из loss и метрик.
3. U-Net с ResNet-18 encoder без предобученных весов успешно выполнила
   forward pass на GPU: вход (4, 3, 512, 512), выход (4, 5, 512, 512),
   14.33 млн параметров.
4. Smoke training на 200 train- и 64 validation-тайлах: за 3 эпохи train
   loss снизился с 2.0265 до 1.5921, validation loss — с 1.7651 до 1.5313.
5. Overfit test на 16 фиксированных train-тайлах показал, что модель
   воспроизводит крупную форму водного объекта на обучающем тайле. Это
   подтверждает работоспособность загрузки, отображения классов, loss и
   backpropagation; данный результат не используется как оценка качества
   или обобщающей способности.
