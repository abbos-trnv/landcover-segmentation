# Fixed-budget comparison protocol

## Причина

Полное обучение одного запуска на 8 677 train-тайлах занимает порядка
9--10 часов в доступной Kaggle-инфраструктуре. Полный трёхмодельный
benchmark в этих условиях не выполним в срок без ухудшения воспроизводимости
или скрытого сокращения эксперимента.

Поэтому полный U-Net run сохранён как reference experiment, а прямое
сравнение decoder-архитектур проводится как отдельный **fixed-budget
experiment**.

## Данные

В `scene_split_budget25.json` фиксированы 8 исходных train-сцен: 2 232
тайла 512x512 px (25.7% от полного train-набора). Validation и test части
не меняются: это те же шесть unseen-сцен, что в полном U-Net run.

Поднабор выбран до запуска моделей среди случайных вариантов с seed
`20261005`. Цель — приблизить pixel-wise распределение классов к полному
train-набору с повышенным весом редких зданий, воды и дорог:

- полный train: фон 57.288%, здания 0.862%, лес 34.199%, вода 6.029%, дороги 1.621%;
- budget25 train: фон 59.171%, здания 0.888%, лес 32.205%, вода 6.116%, дороги 1.620%.

Все тайлы одной сцены по-прежнему принадлежат ровно одному split.

## Сравниваемые модели и одинаковые условия

U-Net, FPN и DeepLabV3+ с ResNet-18 encoder без предобученных весов.
Для всех: одинаковые тайлы, seed, Cross-Entropy + Dice, аугментации,
AdamW, LR 3e-4, weight decay 1e-4, batch size 8, максимум 30 эпох и
early stopping patience 8.

Выбор checkpoint выполняется только по validation foreground mIoU. Test
используется один раз после фиксации каждого запуска.

## Корректная интерпретация

Этот эксперимент отвечает на вопрос о сравнительном поведении decoder-типов
при одинаковом ограниченном вычислительном и дата-бюджете. Он не заменяет
полный U-Net reference run и не должен интерпретироваться как оценка
предельного качества архитектур при неограниченном времени обучения.
